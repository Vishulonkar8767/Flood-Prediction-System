AI-Based Flood Prediction System

An academic Machine Learning project that predicts flood risk from environmental and weather parameters, with a full interactive web dashboard.

Problem Statement

Floods are among the most destructive natural disasters, causing loss of life, property damage, and disruption of infrastructure. Early and accurate flood risk prediction can help authorities and communities take timely preventive action. Traditional forecasting methods are often slow or require specialized hydrological models; this project explores whether a lightweight, data-driven ML model can flag flood risk from commonly measured environmental parameters.

Objective

To design, train, and deploy a machine learning classification model that predicts the probability of flooding based on parameters such as rainfall, river water level, river flow, soil moisture and more — and to present this in an interactive, easy-to-use web dashboard suitable for a live academic demonstration.

Dataset

A synthetic dataset of 1,500 records was generated (see generate_dataset.py), covering 11 environmental parameters: Rainfall, Temperature, Humidity, River Water Level, River Flow, Soil Moisture, Wind Speed, Atmospheric Pressure, Previous Rainfall, Drainage Capacity, and Elevation. Rather than assigning random labels, the target Flood column is derived from a weighted risk score built from these parameters (with realistic relationships — e.g. higher rainfall and river level increase risk, higher drainage capacity and elevation reduce it), passed through a sigmoid function with noise, so the resulting patterns are learnable yet realistic.

Machine Learning Algorithms
  • Random Forest Classifier — an ensemble of decision trees, generally the most robust performer and used for feature-importance explainability.
  • Decision Tree Classifier — a single interpretable tree-based model.
  • Logistic Regression — a linear baseline model for binary classification.

All three are trained and compared on Accuracy, Precision, Recall, F1-score and Confusion Matrix. The best performer (by F1-score) is saved and used for live predictions.

Technologies Used
Python Pandas NumPy Scikit-learn Matplotlib Seaborn Flask HTML5 CSS3 JavaScript Bootstrap 5 Chart.js SQLite Joblib
Prediction Methodology
  1. User enters environmental parameters manually or generates a random realistic sample.
  2. The frontend sends the values as JSON to the Flask /predict endpoint.
  3. Values are validated, scaled with the saved StandardScaler, and passed to the trained model.
  4. The model returns class probabilities, from which a Flood/No-Flood label and a risk level (LOW / MEDIUM / HIGH) are derived.
  5. The result is displayed instantly and logged to the prediction history database.
Benefits
  • Fast, low-cost risk screening
  • Interactive, easy to demonstrate
  • Explainable via feature importance
Limitations
  • Trained on synthetic, not real, sensor data
  • Does not model complex hydrology/terrain
  • Not a replacement for official flood warnings
Future Scope
  • Integrate real-time weather/river-gauge APIs
  • Add satellite/GIS elevation data
  • Deep learning (LSTM) for time-series forecasting
